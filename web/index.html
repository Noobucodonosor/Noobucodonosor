Kit Server Locale / Cloud Run

Avvia il tuo Proxy Free-Tier in 1 comando

Zero dipendenze npm (solo Node.js 22). Copia .env.example in .env, inserisci una chiave gratuita (Gemini, Groq o OpenRouter) e avvia l'hub completo in locale o su Cloud Run. 

git clone https://github.com/Noobucodonosor/Noobucodonosor.git
cd Noobucodonosor
cp .env.example .env
node server/index.mjs
